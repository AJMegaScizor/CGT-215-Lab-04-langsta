A program that solves factorial, arithmetic series, and geometric series problems. 
The user has a choice at launch of:
1. Factorials
2. Arithmetic Series
3. Geometric Series
4. Exit
The selection depends on the key entered by the user.
When asked to define variables that must be natural numbers, the program will keep printing a request to enter a positive number until the user enters a positive number.
The user is able to rerun the program operation at the end of each selection to try running a new selection by entering "y" or to suspend the program with "n."
